# Evidence roadmap

[中文](#中文) · [Showcase overview](../README.md)

## 0.2.x: documentation and localization

Changes in 0.2.x are limited to documentation and localization revisions. Version 0.2.14 brings web-chat planning and review with local-agent execution to the front, using the existing MountainRS retrospective, public Stage 7.3 files and an original progress capture. This documentation revision adds no new client integration or fresh-client acceptance result. Version 0.2.12 connects the English reading path to the MountainRS overview and retrospective, uses the original PF3 tree screenshot with adjacent English translations, and publishes the actual resume text including rules and asset locations. Version 0.2.11 leads with assembled handoff context and pairs selected live MountainRS reads with the existing project tree. The research repository is now public. Version 0.2.10 adds an English default protocol demo and an explicit Chinese command, sharing the unchanged reference implementation. Version 0.2.9 organizes the README around the project, the handoff problem, the [MountainRS workflow snapshot](mountainrs.md) and the runnable example. Author and contact information sit at the end. The v0.2.3 contract semantics and v0.2.4 engineering checks remain the baseline. See the [engineering record](engineering-v0.2.4.md).

## Next evidence milestone: 0.3.x

[MountainRS](https://github.com/zhaoxiuyue/MountainRS/blob/main/README.en.md) is public as of September 18, 2026, with reports and selected result tables. The next evidence milestone is a documented fresh-client handoff tied to those artifacts: what the new client read, checked and wrote back. Publishing the research repository and inspecting its recorded workflow do not by themselves complete that test. There is no announced release date.

## 中文

0.2.x 只接文档与本地化修订。v0.2.14 将网页设计与审查、本地执行的协作过程放到前面，使用已有 MountainRS 复盘、Stage 7.3 公开文件与原始进展截图；本轮文档修订不新增客户端接入或新客户端验收结果。v0.2.12 接通 MountainRS 英文首页与协作复盘，撤去重画的树图与续接卡片，使用原始界面截图配英文翻译，并公开包含规则正文、资产位置的真实续接文本。v0.2.11 以组装续接上下文为首页主线，将 MountainRS 的精选实时读取与已有项目树配对，并链接现已公开的科研仓库。v0.2.10 提供默认英文、显式中文的协议示例，两种语言共用未改动的参考实现。v0.2.9 按项目本身、接手问题、[MountainRS 工作流快照](mountainrs.zh-CN.md)与运行示例组织 README，作者和联系方式放在末尾；沿用 v0.2.3 的契约语义与 v0.2.4 的工程检查。详见[工程记录](engineering-v0.2.4.md)。

[MountainRS](https://github.com/zhaoxiuyue/MountainRS) 已于 2026 年 9 月 18 日公开报告与精选结果表。下一证据里程碑是与这些产物对应的新客户端续接实录：它读了什么、核验了什么、写回了什么。公开科研仓库与查看已记录的工作流，本身不等于完成这项实测。目前没有发布日程。
